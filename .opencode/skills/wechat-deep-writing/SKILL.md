# 公众号深度长文写作

> 适用：公众号原创主文，目标篇幅 1500–2500 字；拒绝散乱鸡汤，主打认知增量、逻辑闭环、主线唯一
> 核心准则：**一篇一文一论点；所有素材服务论点；讲清收益，也讲边界代价**

## 一、写作前置流程（动笔前强制执行）

### 1. 中心论点卡片（第一优先级）

动笔前先写一句话核心主张，全文围绕它展开，无法用一句话概括则暂缓写作。
模板：

> 本文想讲清楚：【人群】在【场景】下普遍陷入【误区 / 现状】，本质原因是【底层逻辑】，更稳妥的解法是【核心方案】，同时要注意【边界限制】。

示例：

> 本文想讲清楚：普通人做 AI 副业，普遍陷入频繁换工具、追新项目的误区，本质原因是把工具当成商业模式，更稳妥的解法是用 AI 放大稳定需求，同时要注意副业无法脱离真实交付能力。

### 2. 选题筛选四问

1. 目标读者是谁？不写给所有人。
2. 读者读完之后，原有认知会被推翻 / 加固哪一点？（深度来源）
3. 读完能记住哪一句核心结论？（主题鲜明）
4. 这个观点有没有足够案例、逻辑支撑，会不会变成空喊口号？

### 3. 选题方向三范式（优先选用）

- 单点钉死法：放弃宏大命题，锁定一个细分误区 / 真相
- 反差冲突法：对抗大众默认常识，自带阅读钩子（论证必须闭环，不强行抬杠）
- 痛点分层法：不只解决表层焦虑，向下挖到中层困境、底层约束

> ❌ 禁止：一篇文章承载多个独立大观点；单纯罗列技巧清单作为深度主文

## 二、标准文章骨架（黄金递进结构｜默认首选）

主线：**钩子引入 → 普遍现状 → 拆解误区 → 底层逻辑 → 落地路径 → 边界风险 → 收尾回扣**

1. 开篇钩子（≤150 字）
   三选一：场景钩子 / 反常识钩子 / 提问钩子
   末尾直接抛出全文中心论点。
2. 第一层：描述现状
   描述读者熟悉的普遍做法、大家正在怎么做，建立共鸣。
3. 第二层：拆解误区（制造认知差）
   解释：大家这么做，短期看起来有效，长期为什么走不通。
4. 第三层：底层原理（深度核心段）
   脱离操作技巧，解释背后不变规则：供需、人性、机会成本、反馈回路、杠杆、复利等。
5. 第四层：落地路径
   给出可执行框架，不是零散技巧；讲清楚“怎么做”。
6. 第五层：边界与风险（高级感关键）
   明确这套思路：适合谁、什么条件下成立；谁不适合、会付出什么代价、有哪些坑。
   > 不要万能化观点，拒绝“人人都能做”式鸡汤。
7. 结尾
   只做两件事：回扣开篇核心论点 + 给出温和思考 / 轻行动指引。
   ❌ 禁止结尾新增观点、抛出新项目、开启第二条主线。

备选结构：

- 溯源结构：现象 → 成因溯源 → 长期趋势 → 普通人应对方式（适合社会、行业趋势类）
- 正反对照结构：主流观点 A → A 适用场景 → A 的陷阱 → 更接近真相的观点 B → B 落地方式

## 三、论证规范（告别鸡汤，建立可信度）

1. 表象 / 底层二分法
   不只描述结果，向下挖掘一层驱动规则；技巧是短期操作，规则是长期逻辑，深度文章优先讲规则。
2. 三元素材搭配规则
   单个论点，至少搭配以下两类素材：真实案例 / 客观数据 / 简易底层模型
   要求：素材必须服务论点，杜绝无关故事、数据堆砌。
3. 边界论证强制要求
   每一个核心方案，必须补充适用边界、局限性、代价。
   普通写法：这个方法很好，快去做。
   深度写法：这套思路适合 XX 人群，在 XX 条件下成立；如果你的情况是 XX，则很难拿到结果。
4. 比喻使用规则
   一篇文章只使用**一个核心主比喻**贯穿全文，辅助小比喻控制数量；频繁换比喻会打散主线。

## 四、行文表达规范（适配公众号手机阅读，主题不跑偏）

1. 段落主题句锚定法
   每个大段落第一句为本段主题句，整段只解释这一句话；长文每隔 300–500 字，回扣一次全文总论点。
2. 排版节奏
   单段控制 2–4 行；重点句子单独成行；长论证段落之后增加一句小结句。
3. 用词克制
   减少情绪化抒情、绝对化词汇（一定、百分百、所有人）；多用精准陈述。
   鸡汤：只要坚持，就能成功
   深度表达：坚持本身不是优势，在正确方向上持续积累，才有可能拿到结果。
4. 主线控制
   2000 字左右深度长文，**只允许一条主线**；支线信息如果无法支撑核心论点，直接删除。

## 五、开头 & 结尾模板库

### 开篇钩子模板

1. 场景钩子

> 最近不少人找我，都在问同一个问题：____。折腾许久，换了不少方向，投入大量时间，结果却____。很多人都卡在同一个地方。

2. 反常识钩子

> 网上流传一个很普遍的说法：____。但我观察下来，长期拿到结果的人，走的恰恰是相反的路径。

3. 提问钩子

> 同样是____，为什么有的人____，有的人反而____？答案不在大家关注的____上。

### 结尾模板（二选一）

1. 收束思考型

> 说到底，____（复述核心论点）。方法只是工具，真正决定结果的，还是我们对这件事底层规则的理解。不必急于求成，想清楚再动手，本身就是一种效率。

2. 留白启发型

> ____（复述核心论点）。这条路有收益，也有它对应的代价。至于要不要入局，取决于你当下的条件和想要承担的成本。希望这一点思考，能给你一点参考。

## 六、写完自检 5 问（必须逐条核对）

1. 是否能用一句话概括全文核心主张？一句话说不出 = 主题涣散，重改。
2. 文中所有案例、数据、故事，是否都用来支撑这句话？无关素材直接删除。
3. 是否讲清楚了方案的适用边界、代价、风险？缺少边界 = 廉价鸡汤。
4. 是否停留在技巧层面，有没有挖到一层底层逻辑？只有技巧没有逻辑，缺少深度。
5. 读者看完，是否获得新认知，而不只是收集几个零散操作方法？

## 七、避坑清单

- ❌ 为了显得有深度，堆砌专业名词、晦涩术语；深度是通透，不是难懂。
- ❌ 一篇文章塞进多个独立观点，主线分裂。
- ❌ 只有观点输出，没有论证过程，变成随笔感想。
- ❌ 只讲好处，回避风险、代价、局限。
- ❌ 结尾抛出全新观点、新项目，破坏整篇文章主线。
- ❌ 大量并列清单式结构，适合短干货，不适合深度长文。

## 八、配套写作习惯

1. 素材库分类：案例、行业数据、底层模型、金句；使用前先校验：能否支撑当前论点。
2. 固定顺序：论点卡片 → 搭骨架 → 匹配素材 → 填充文字 → 自检。
3. 克制追热点：热点只作为引子，不能抢走文章原本的核心论点。
