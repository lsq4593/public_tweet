# 我开始和 AI 对练，而不是问它要答案｜AI 动手手册 · 用法训练

有段时间我用 AI 的姿势很统一：题目扔进去，等一份像样的答案，改两句，交差。

快，是真的快。  
空，也是真的空。

最快的一次，我让它写完一段我「应该会」的说明，自己读第二遍才发现——**有一半我讲不出来。** 不是不会打字，是离开提词器，就把那件事说不圆。

那天晚上我想起岗位那篇里空着的几行：真正值钱的，往往是写不成一句完整提示词的判断。也想起后来那句——AI 很会交形状，分量还在人身上。

于是我改了一个很小的习惯。

**不再默认问「给我答案」。**  
**改成问：「你出题，我先做，你再批。」**

我把这叫对练。

---

## 一、我具体做了什么

规则定得很死。连续两周，每天大约二十五分钟。

选一个我「以为自己会」的小主题——把需求含糊处问清楚、把一段逻辑讲给外行、当场解释上周刚写过的模块。

然后四步，顺序不许反：

1. **我先讲三分钟**（或不写提示词，先自己写一段）  
2. **再让 AI 基于我的目标出题**（刁难可以，替我答不行）  
3. **我限时作答**  
4. **它只批：空话、漏洞、我不敢负责任的句子**——禁止写「参考范文」，除非我明确要求

第一周我破功四次。每一次都是同一动作：做到一半觉得丢人，手比脑子快，打出「那你直接给一版吧」。

给是给了。漂亮。  
**关掉对话框之后，身上仍旧不会。**

第二周我加了一条羞辱性的约束：**只要中途要答案，今天对练记「逃训」一次。** 逃训可以发生，但必须写进备忘录——不能假装练过。

两周下来，逃训从四次变一次。  
真正留下来的，不是它的范文，是我被追问时出汗的那几回。

有一次它扮演「什么都不懂但有权拍板的人」，连问三个「所以到底要我做什么」。前两个我答得像汇报，第三个卡了二十秒——因为我发现自己根本没想清。

**那二十秒，比任何润色都有用。**

## 二、反常识：对练看起来更慢，其实在救你的「分量」

问答案，你带走形状。  
对练，你被迫把判断在嘴里过一遍。

问答案的励志故事很好写：我会用 AI 了，效率起飞。  
对练的故事难看：我被一个没有体温的东西问住了，发现自己会的比以为的少。

但我越来越觉得，第二种才接近成长。

因为成长很少发生在「获得一份正确文本」的时刻。  
它发生在：**你以为自己懂，被逼着演示，然后穿帮。**

AI 当教练时有一个恶心也珍贵的特点——不太给你面子。你让它刁难，它真的往空处戳。真人师傅有时会顾及你的情绪；对话框不会。

**前提是你真的把「要答案」的手摁住。**

否则它对练两分钟，又变回代写机器。姿势决定关系：你把它当自动售货机，它就卖货；你把它当沙袋和发令枪，它才开始像陪练。

这也和「中空的流利」对着干：对练要的不是屏幕更满，是关掉屏幕以后你还站得住。

## 三、可直接复制的对练壳

我实际在用的三套。按需选，不要一天叠齐。

### 壳 1：讲解 → 出题 → 我做 → 它批（默认日课）

```
我今天要对练的主题：【一句话】
我当前水平：【会一点 / 经常用但不稳 / 几乎靠感觉】
今日目标：【例如：能对外行讲清 / 能扛住三个追问】

请严格按顺序，一次只做一步，等我回复再继续：

第1步：先不要出题。只问我一个问题，迫使我说清「我会的边界」。
（等我答完）
第2步：基于我的目标出 3 道题，由易到难。不要给答案，不要暗示答案。
（等我逐题作答）
第3步：只批改，逐条指出：
- 哪句是空话
- 哪处逻辑跳了
- 哪句我若在真人面前会露馅
不要写范文。除非我说「我要示范」，你才给一个短示范。

额外约束：如果我中途要求你直接给完整答案，请只回复「逃训」，并问我是否今天终止。
```

### 壳 2：刁难对手（面试 / 需求方 / 难缠同事）

```
请扮演【具体角色】。你的目标不是帮我收场，而是揭露我没想清的地方。
场景：【】
我的立场/方案：【我先自己写 5–10 行】

规则：
- 每次只问一个刁难问题，等我答完再问下一个
- 我的回答若空洞，先指出空洞再继续追问，不要替我补全
- 共 5 个来回后停止，给我一张「我暴露的缺口清单」（只列缺口，不给补救答案）
- 禁止安慰，禁止「其实你已经很好了」
```

### 壳 3：周复盘（只看自己有没有变强）

```
这是我本周对练记录（含逃训）：
【粘贴日期、主题、逃训次数、我卡住的原话】

请只做这三件事：
1. 我重复出现的缺口（按频率排序）
2. 下周只练一个缺口的建议（要小到七天能落地）
3. 不要励志总结，不要鼓励句
```

## 四、一张周课表（可贴）

| 日 | 对练什么 | 过关线 |
|---|---|---|
| 一 | 把本职一件事讲给外行听 | 对方（AI）追问两次仍不崩 |
| 二 | 刁难追问：需求含糊 / 为什么选这个 | 能承认「不知道」并给出确认动作 |
| 三 | 限时口述：上周自己做过的一件实活 | 不看稿讲满 90 秒且无假数 |
| 四 | 反方练习：让它攻击我的方案 | 我能复述攻击点，而不是辩赢 |
| 五 | 弱项加练：本周穿帮最多的一类 | 同一题隔天再考，错因要变少 |
| 六日 | 休息或只做壳 3 复盘 | 有记录即可，不硬练 |

**过关线写的是你，不是它。**  
它输出再华丽，也不算你练过。

## 五、两个必须知道的坑

**第一，对练也会上瘾成表演。**

我试过为了「看起来被批得很惨」而故意答得很烂，换它一串严厉点评，自己收获一种假勤奋的悲壮感。那是戏，不是练。

判定方法很简单：明天同一题，你能不能答得比今天实一点。变了，才叫练。

**第二，别让陪练越权成裁判人生。**

它可以戳逻辑空洞，不该替你下「你适不适合这行」的判词。那类问题一出现，就停。分量在你，也在真实世界的反馈里——客户、同事、线上结果——不在对话框的语气里。

还有：涉及医疗、法律、安全的硬知识，对练只能练「表达与提问」，不能练成「它说对我就信」。该查官方、该问人的，还是走原渠道。

## 聊聊

**你用 AI 更常要答案，还是更常让自己先答？**

我以前几乎全是前者。改成对练之后，效率账变难看了，但穿帮变少了。

**第二个**：你最近一次「其实讲不出来却交了漂亮稿」，卡在什么事上？

---

**AI 可以交答案，但成长很少写在答案上——它写在你被追问到出汗、却还肯再答一轮的时候。**
