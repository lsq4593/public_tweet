# 我用 AI 把年度目标拆成每周只做一件事｜AI 动手手册 · 行动目标

年初我最擅长的事，不是做事，是**同时想做很多事**。

备忘录里躺着健身、阅读、副业、英语、整理人生——每条都写得像要认真过这一年。周一早上打开一看，五条一起发光，于是一条都点不下去。

我不是没拆过周计划。拆过，而且拆得很勤：一星期塞七件「关键动作」，美其名曰节奏感。周末一对账，常常是七件都动过一点，七件都没落地。

后来我给自己加了一条难看的规矩，并让 AI 来守门：

**年度目标可以很多；每周只允许一件事进「本周唯一」。**

其余全部降级：旁观、排队，或直接承认是海报。

---

## 一、我具体做了什么

我先把年初那串目标原样贴出来——九条，和盘点篇里审计过的那批同源。有的已完成，有的是空壳。

然后不做「智能排期」。我只让 AI 干一件冷酷的事：**逼我选出本周唯一，并写成可交的一件。**

```
今天是【日期】。下面是我的年度目标原文（不许美化）：
【粘贴】

规则：
1. 本周只允许 1 条进入「本周唯一」
2. 请追问我：若本周只能推进一条，哪条不做会最痛？为什么？
3. 选定后，把它压成「本周唯一卡」：
   - 本周唯一（一句话）
   - 最小可交版（丑但周日能验收）
   - 验收标准（可打勾）
   - 和其他目标的关系：【排队】【旁观】【本周明确不碰】
4. 禁止：均衡推进、每周七件、励志时间表
若我说「这几条都很重要」，请回：重要不构成同时开工的许可证——请砍到 1。
```

第一周我选得很体面：「系统提升表达」。AI 追问最小可交版时，我卡了。那条被踢回愿望墙。

重选后变成：**周日 22 点前，把上周一个工作模块对外行讲满 90 秒，并留下逐字稿或可回放的口述记录。**

那周我只盯这一件。健身房海报还在，英语 App 还在——**但不许进本周唯一栏。** 周五想加塞「顺便把阅读也捡起来」，我让 AI 按规则拒绝。它拒了。我居然有点不爽，也正因为不爽，规则才像规则。

周末验收：交了。很难看，但算数。

连续四周后，我的体感很明确——

**不是年度目标变少了，是每周的假忙碌死了一批。**  
一年若真有 50 个有效周，每周一件，也远比每周七件空转要像「过了一年」。

## 二、反常识：年度感来自「每周唯一」，不是来自清单长度

鸡汤喜欢说：目标要全面，人生要平衡，周计划要覆盖各板块。

我实测更扎人的是——

**同时亮灯的目标越多，越像展览，越不像执行。**

清单长度安慰的是自我形象：我是一个有追求的人。  
每周唯一惩罚的是注意力：你到底肯为哪一件付出现实成本。

AI 在这里的价值也很具体：不当生活教练排七彩课表，当那个重复念「只能一件」的门卫。你一求平衡，它就该问：平衡是愿望，还是本周的交付义务？

这和前几篇是同一条绳上的结：

- 最小行动：今天空转时，先吞一剂
- 定时交付：到点交或砍
- 年度盘点：用证据算完成率
- **每周唯一：从年度清单里，只放行一件进本周**

形状上，一张卡。  
分量上，你要忍受「别的也很重要却本周不碰」的内疚——那点内疚，往往比勤奋感更接近行动。

## 三、可复制：三张卡

### 卡片 A：周一选唯一（5–10 分钟）

```
今天周一。年度目标如下：
【粘贴】

上上周/上周「本周唯一」结果：【交/砍/无】

请逼我生成本周唯一卡：
- 本周唯一：
- 最小可交版：
- 验收：
- 截止：本周日【具体时刻】
- 本周明确不碰：【至少列出 2 条我很想碰但禁止的】

我说「能不能两件」时，请只回：不能。选 1，或承认本周放假。
```

### 卡片 B：周中加塞拦截（想加戏时用）

```
本周唯一是：【】
我现在想加塞：【】

请判定：
【拦截】加塞会稀释唯一 → 拒绝，并重述本周验收
【可旁观】加塞若 ≤10 分钟且无交付义务，可记入旁观，但不进唯一栏
【应换唯一】若加塞才是真痛点，请启动换卡流程：旧唯一必须先交或砍，才能换新

禁止鼓励「你很拼」。
```

### 卡片 C：周日验收（只问这一句）

```
本周唯一：【】
原定验收：【】

我只能回：
1）交：【证据】
2）砍：【一句真实原因】
3）逃训加塞：【我偷做了哪些非唯一的事】

请记账。若我交了但证据软，降为「形状有了、分量不足」，下周一选唯一时加重追问。
不要安慰。
```

## 四、一张对照（可以截图）

| 多目标并行周 | 每周唯一周 |
|---|---|
| 清单越长越像上进 | 清单可以长，放行只准 1 |
| 每天都碰一点 | 一件做透到可验收 |
| 「顺便」是美德 | 「顺便」默认拦截 |
| AI 帮我排满课表 | AI 守门：只能一件 |
| 周末七件都半成品 | 周末一件有证据，或诚实砍 |

并行曾让我的周计划很好看。  
唯一让我的周日第一次经常有东西可交。

## 五、两个必须知道的坑

**第一，唯一不是「最小到不用做事」。**

「本周想想方向」不算唯一。唯一必须能交：有文件、有发出、有可回放的痕迹。太虚，就降回愿望墙，别占唯一席。

**第二，别用唯一逃避真正痛的那件。**

人会专挑好交的装唯一，把吓人的继续养在清单里充门面。卡片 A 里那句「不做会最痛」就是打这个滑的。痛的那件若连周都不敢进，年度盘点时多半还是海报。

工作上的硬截止日期、家人健康、合同义务，不走「每周唯一」游戏规则——它们是外部强制，该插队就插队；唯一制管的是你那些自我施加的年度抱负，不是拿来挡救命的事。

## 聊聊

**若本周只准一件，你会选哪条——不做会最痛的那种？**

我第一周选错了，选成体面；第二周才选到能出汗的。

**第二个**：你更怕「别的目标被冷落」的内疚，还是更怕「周末又交不出任何一件」？

我以前更怕前者，所以并行。后来发现后者才是年终空账的真相。

---

**年度目标可以很多；每周能进场的，往往只有一件。让 AI 守这道门——不是让你变窄，是让你总算有一周像过完了。**
