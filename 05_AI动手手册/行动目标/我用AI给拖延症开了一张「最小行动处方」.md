# 我用 AI 给拖延症开了一张「最小行动处方」｜AI 动手手册 · 行动目标

拖延对我来说，很少长成「躺平」。

它更常长成另一种体面：**计划很完整，动手很遥远。**

待办写满一屏，拆成十二步，时间块涂得像作战图——今晚实际完成的，往往是：打开文档、改个标题、再关掉。

我试过骂自己，试过激励自己，试过把任务标成刺眼的红。红很醒目。事还是没动。

后来我换了切口：不治「性格」，只开一张处方。

**凡是我拖的事，先逼 AI 开出「最小行动处方」——一次一剂，小到丢人，但今天必须吞下去。**

不求治本。先求今晚不再空转。

---

## 一、我具体做了什么

实验对象很普通：一份拖了很久、「回头再弄」的个人材料包。原话是「系统整理」。

「系统」两个字一出场，我就开始配咖啡、找歌单、调灯光——唯独不碰文件。

我把原话丢给 AI，禁止它做完美计划，只许开方。

```
我在拖延这件事：【原话，允许很烂】

请当处方医生，不要励志，不要人生导师：
1. 先诊断：我拖的是怕失败 / 怕开丑 / 怕太大 / 还是根本不想做（只选主因）
2. 只开「最小行动处方」一剂：
   - 行动：【必须具体到手部动作，例如「新建文件夹并放入 3 个文件」】
   - 时长：【5–15 分钟，禁止超过 25 分钟】
   - 证据：【截图 / 文件名 / 已发出的一条消息】
   - 今日截止：【具体到几点】
3. 写明：吃完这剂，今天即停；其余一概不算今日任务
4. 若我说「太小没意义」，请反驳：意义不在这剂，在打断空转

禁止拆成十步周计划。
```

第一剂开出来，难看到我笑场：

**新建文件夹，丢进任意 3 个相关文件，截图，今晚 10 点前。**

十二分钟做完。材料包并没有变好。  
**但「系统整理」第一次在现实里动了刀，而不是只在脑内彩排。**

后面几天流程定死：拖了 → 开一剂 → 吃完记账 → 明天若还拖，再开下一剂。不准提前开「周疗程」。

一周后，材料包仍不完美。它只是从庞然大物，变成了有骨架的半成品。

我后来才懂：拖延最怕的不是宏大计划，是**连续几天都留下难看的开工痕迹**。

## 二、反常识：拖延的对手往往不是动力，是剂量

鸡汤会说：你缺愿景、缺为什么、缺燃烧的心。

我更常撞上的是另一件事——

**剂量开大了。**

「系统学习」「全面整理」「认真准备」句句正确，动手时却像一口吞下一周的药。大脑的保护机制很朴素：太大，就拖；一拖，就继续用计划证明「我还在场」。

最小行动处方干的是反励志的活：

**把任务降到你不好意思再说「没时间」的尺寸。**

五到十五分钟。必须有手部动作。必须有证据。  
丑，但可吞。

AI 在这里也不当拉拉队。它当那个死活只肯开小剂量的医生：你一求「给我完整方案」，它就把你打回——先吃今天这一剂。

它和定时交付是亲戚，切口不同：

- 定时交付管：**到点，交或砍**
- 最小行动管：**还没到死线，但今天已经空转**——先打断循环，再谈交砍

形状上，一张小处方就够。  
分量上，签字的仍是你：证据在不在，循环断没断。

## 三、可复制：三张处方卡

### 卡片 A：开方（拖了就用）

```
我又在拖：【】
已空转大约：【多久】

请开「最小行动处方」一剂（缺一不可）：
- 诊断（一句，不准鸡汤）
- 行动（手部动作级）
- 时长（5–15 分钟）
- 证据（可打勾）
- 今日截止时刻
- 吃完即停：今日不许加量

若我要求「顺便把整周也安排了」，请拒绝，只回：今晚只许这一剂。
```

### 卡片 B：兑药（做完打卡）

```
处方：【粘贴】
我实际做的：【】
证据：【】
耗时：【】

请只判定其一：
【足量】证据对得上行动
【偷工】看起来忙，没碰到核心动作
【加量成瘾】偷偷做太大，明天可能报复性拖延

禁止夸奖。若偷工，重开一剂：比上一剂更小、更贴手。
```

### 卡片 C：三日疗程（只盯同一件事）

```
同一拖延事项，三天的处方与结果：
Day1：【】
Day2：【】
Day3：【】

请只答：
1. 循环有没有被打断（没有证据链，不算）
2. 下一步：继续最小剂量，还是够格升成「定时交付卡」（交/砍）
3. 不要励志总结
```

## 四、一张对照（可以截图）

| 大计划拖延期 | 最小行动处方期 |
|---|---|
| 先追求完整方案 | 先追求今天可吞的一剂 |
| 打开文档就算努力 | 手部动作 + 证据 |
| 「没状态」可以合法停摆 | 「没状态」也先吃 5 分钟 |
| AI 帮我拆成二十步 | AI 只开一剂，并拦加量 |
| 第二天从零感动自己 | 第二天接着昨天的痕迹 |

完整方案曾让我很像专业人士。  
小剂量让我第一次连续三天，都真的碰得到那件事。

## 五、两个必须知道的坑

**第一，最小不是假装做了。**

「打开软件待五分钟」常常是安慰剂。处方必须碰到核心动作：文件被挪动、字被写下、消息被发出。卡片 B 的「偷工」，就是打这个假的。

**第二，别把小剂量开成终身躲避。**

连续三天有证据之后，该升定时交付就升——给死线，给交或砍。最小行动是急救，不是让大事永远以「我在一点点弄」的名义住院。

涉及健康、金钱、法律的事项，小剂量只帮你开工和整理信息，不能替代就医、顾问和正式手续。

## 聊聊

**你最近拖得最久的一件事，若只许开 10 分钟处方，行动能小到哪一步？**

我那次是「丢进 3 个文件」。丢脸，但管用。

**第二个**：你更常死在「计划太大」，还是死在「做了一点就加量，然后撑爆、隔夜更拖」？

我两种都有。后者更隐蔽——假勤奋的报复，通常隔夜就到。

---

**拖延不一定缺愿景；它常常只是剂量开大了。先让 AI 开一剂小到丢人的，吃下去——循环断了，再谈交或砍。**
